# MeeriDEX und MeeriDex Companion

Tierverwaltung im Retropixelstil: MeeriDEX für Windows und MeeriDex Companion für Android, mit verschlüsseltem Sync im selben WLAN.

## Downloads und Updates

- [MeeriDEX für Windows](https://github.com/Coupe5E/MerriDex/releases/latest): MeeriDEX.exe oder MeeriDEX-Testversion.zip.
- [MeeriDex Companion für Android](https://github.com/Coupe5E/MerriDex/releases/tag/companion-v0.3.1): APK über die bestehende App installieren.

Die Update-Funktionen verwenden weiterhin dieses öffentliche Repository. Tierdaten und Profile bleiben auf den eigenen Geräten. Die Downloads enthalten keine persönlichen Daten.
