# MeeriDEX

Dein Meeri-Lexikon für Windows: Tierprofile, Stammbäume, Verpaarungen, Abgaben, WurfOrakel und Krankenstation im Retropixelstil.

## Download und Updates

Die aktuelle Version gibt es unter [Releases](https://github.com/Coupe5E/MerriDex/releases/latest). Für neue Installationen **MeeriDEX.exe** oder **MeeriDEX-Testversion.zip** herunterladen.

Bestehende Installationen aktualisieren sich beim Programmstart oder über „Updates prüfen“. Tierdaten und Profile bleiben erhalten. Die Downloads enthalten keine persönlichen Tierdaten.

## Neuer Name, vertraute Meeris

Seit Version 1.1.9 heißt das Programm **MeeriDEX**. Die GitHub-Adresse und ein identischer Download namens MerriDex.exe bleiben für ältere Updater bestehen. Regulärer Programmname und neuer Download sind MeeriDEX.
